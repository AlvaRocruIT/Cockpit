Project: Client Project Reporting Dashboard

Purpose:
Transform an Excel project plan into a client-facing reporting system.

Roles:
- Admin
- Client

Core Features:
- Sprint tracking
- Task tracking
- Client feedback
- PDF export
- Email notifications
- Multi-client support
- Excel import

Task Status:
- Achieved
- In Progress
- Delayed
- Upcoming

Progress Rules:
- Only Achieved contributes progress.
- Sprint progress = achieved tasks / total sprint tasks.
- Overall progress = achieved task weight across project.

Permissions:
- Clients can create/edit feedback.
- Admin cannot modify client feedback.

Future Features:
- Automated email reporting.
- Historical reporting.
- Advanced analytics.
